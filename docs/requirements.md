# Java / Scala 编程学习站需求摘要

## 项目目标

建设一个面向同学公开学习的 Java / Scala 编程学习站。网站以学习路线为入口，以章节为组织方式，以每节课的公开讲义、知识点和互动练习为学习单元。

## 页面结构

- 首页：展示 Java 学习和 Scala 学习两个主入口。
- Java / Scala 入口页：展示章节路线、学习进度感、重点知识地图和课程列表。
- 讲义库：集中展示公开课程讲义，支持筛选与搜索。
- 课程详情页：展示课程摘要、知识点、代码示例和互动练习。
- Java 互动练习专区：保留已有 Java 小游戏入口。

## 首页功能

- 展示 Java / Scala 两个清晰入口
- 展示课程数量、讲义数量、互动练习数量等概览
- 展示推荐起步课程
- 引导进入讲义库和互动课程

## 课程详情页模块

- 课程基本信息
- 课程摘要
- 知识点拆解
- 代码示例
- 小测验
- 拖拽匹配
- 流程动画
- 练习题
- 课程讲义

## 技术方案

采用纯 HTML / CSS / JavaScript。

原因：

- 适合 GitHub Pages 部署
- 不需要后端
- 不需要数据库
- 后续更新简单
- 小白更容易维护

## 后续更新方式

以后新增课程时，主要修改 `js/data.js` 和公开讲义数据。原始整理资料不放入公开仓库，只保留在本地私有目录。
