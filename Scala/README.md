# Scala 课程资料说明

这个目录只保存允许公开发布的 Scala 学习资料，包括整理后的课程讲义源文件和用于网站课程数据的生成资料。

## 目录作用

### `课程总结/`

保存整理后的 Scala 课程讲义源文件，适合快速复习、查找示例和生成网站课程内容。

命名格式：

```text
课堂总结 M-D Scala课程主题-上.md
课堂总结 M-D Scala课程主题-下.md
```

如果当天只有一份内容，可以不使用“上/下”后缀。

### `生成资料/`

保存按课程日期分批生成的中间产物。每个批次通常包含：

- `*-summary.md`：该批次的 Markdown 课程摘要。
- `*-data-object.js`：可合并到网站主数据的课程对象。
- `README_使用说明.md`：该批次的导入说明。

这些 JavaScript 文件是生成资料，不会被网页直接加载。网站实际读取的课程主数据位于项目根目录的 `js/data.js`。

## 私有源资料

详细源资料不放在公开项目中。本机保留位置：

```text
D:\桌面\Project\School\private_course_sources\scala_learning_site\Scala\
```

公开仓库只发布整理后的讲义、互动课程数据和生成页面。

## 新增课程建议流程

1. 将整理后的课程讲义保存到 `课程总结/`。
2. 如果生成了网站数据对象，将完整批次保存到 `生成资料/YYYY-MM-DD-主题/`。
3. 检查课程 `id` 不重复后，再将数据对象合并到 `../js/data.js`。
4. 运行 `npm run build:summaries` 和 `npm test`。
5. 打开首页、Scala 学习页、讲义页和课程详情页，确认链接正常。
